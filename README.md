# LeaveManager (Java)

Personel izin takip sistemi. Proje kuralları: `AGENTS.md`.

Calistirma (JDK 21, `JAVA_HOME` JDK 21'i göstermeli):

    "$JAVA_HOME/bin/javac" --release 21 -d out src/Main.java
    "$JAVA_HOME/bin/java" -cp out Main

Adres: http://localhost:5000

Doğrulama: `./scripts/check` (hızlı: `./scripts/check --fast`).
